# CivicTwin-R — Data Dictionary

## Telemetry Message Schema (v1.0)

The canonical telemetry payload used across all components.

| Field | Type | Required | Description | Example |
|-------|------|----------|-------------|---------|
| `schema_version` | string | Yes | Schema version identifier | `"1.0"` |
| `device_id` | string | Yes | Unique device identifier (1–64 chars) | `"node_01"` |
| `zone_id` | string | Yes | Monitoring zone identifier | `"zone_01"` |
| `sequence` | integer | Yes | Monotonically increasing message counter (≥0) | `1024` |
| `timestamp` | ISO-8601 | Yes | Measurement time in UTC | `"2026-01-15T10:30:00Z"` |
| `distance_cm` | float | No | Raw sensor distance reading (cm) | `12.4` |
| `water_level_cm` | float | No | Computed water depth (cm) | `17.6` |
| `water_level_pct` | float | No | Normalized fill percentage (0–100) | `58.7` |
| `rain_sensor_raw` | integer | No | Raw simulated analog rain-input ADC count (0–4095) | `2048` |
| `rain_indicator_pct` | float | No | Uncalibrated simulated rain indicator (0–100%), not mm or mm/h | `50.0` |
| `sensor_status` | enum | Yes | Sensor state | `"valid"` |
| `source` | enum | Yes | Data origin | `"simulator"` |
| `quality_flags` | string[] | No | Quality annotations | `["noisy"]` |

### Sensor Status Values

| Value | Meaning |
|-------|---------|
| `valid` | Normal successful reading |
| `invalid` | Sensor returned out-of-range or no data |
| `stale` | Reading is older than the stale threshold (30s) |
| `offline` | Device or network is disconnected |
| `simulated` | Reading produced by the digital twin simulator |

### Data Source Values

| Value | Meaning |
|-------|---------|
| `physical` | From a physical ESP32 sensor |
| `wokwi` | From a Wokwi-simulated ESP32 |
| `simulator` | From the Python sensor simulator |
| `digital_twin` | Generated by the digital twin engine |
| `reconstructed` | Reconstructed from missing-data algorithm |

For Wokwi telemetry, `rain_sensor_raw` and `rain_indicator_pct` come from a
potentiometer used as a simulated analog rain-sensor stand-in. The indicator is
not a calibrated rainfall measurement and must not be interpreted as millimetres
or millimetres per hour. Such records include the quality flag
`rain_indicator_uncalibrated` and retain `source = "WOKWI_SIMULATED"`.

The digital-twin model's `rainfall_input_mm` is a hypothetical model input. It
is separate from the Wokwi analog indicator and is not populated from these
telemetry fields.

## Ingested Telemetry (Extended)

The ingestion service adds these fields:

| Field | Type | Description |
|-------|------|-------------|
| `ingestion_timestamp` | ISO-8601 | Server-side receive time |
| `is_duplicate` | boolean | Message was a duplicate |
| `is_stale` | boolean | Message arrived past stale threshold |
| `is_reconstructed` | boolean | Value was reconstructed |
| `reconstruction_method` | string | Algorithm used (`locf`, `linear`) |
| `scenario_id` | string | Associated scenario identifier |

## SQLite Schema

Table: `telemetry`

| Column | Type | Constraints |
|--------|------|-------------|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT |
| device_id | TEXT | NOT NULL |
| zone_id | TEXT | NOT NULL |
| sequence | INTEGER | NOT NULL |
| event_timestamp | TEXT | NOT NULL (ISO-8601) |
| ingestion_timestamp | TEXT | NOT NULL (ISO-8601) |
| distance_cm | REAL | Nullable |
| water_level_cm | REAL | Nullable |
| water_level_pct | REAL | Nullable |
| rain_sensor_raw | INTEGER | Nullable |
| rain_indicator_pct | REAL | Nullable |
| sensor_status | TEXT | NOT NULL |
| source | TEXT | NOT NULL |
| is_reconstructed | INTEGER | DEFAULT 0 |
| reconstruction_method | TEXT | Nullable |
| scenario_id | TEXT | Nullable |
| quality_flags | TEXT | DEFAULT '[]' (JSON array) |

Unique constraint: `(device_id, sequence)`
Index: `(zone_id, event_timestamp)`

## InfluxDB Schema (when enabled)

- **Bucket:** `telemetry`
- **Measurement:** `water_level`
- **Tags:** `device_id`, `zone_id`, `sensor_status`, `source`
- **Fields:** `distance_cm`, `water_level_cm`, `water_level_pct`, `rain_sensor_raw`, `rain_indicator_pct`, `sequence`
- **Retention:** 7 days (configurable)

**Important:** Tags should be low-cardinality. Do not use `sequence` or
`timestamp` as tags.

## Conversion Formulas

```
distance_cm    = raw HC-SR04 echo time × 0.0343 / 2
water_level_cm = container_height_cm - distance_cm
water_level_pct = (water_level_cm / container_height_cm) × 100

Clamping: 0 ≤ water_level_cm ≤ container_height_cm
          0 ≤ water_level_pct ≤ 100
```
